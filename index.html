연동 설정

권장 방식입니다. Google 로그인 후 읽기 전용 권한으로 일정을 불러옵니다.

  1. Google Cloud에서 새 프로젝트를 만들고 Google Calendar API를 사용 설정합니다.
  2. Google Auth Platform에서 동의 화면을 구성합니다. 외부 앱 테스트 중이라면 theldancehall@gmail.com을 테스트 사용자로 추가합니다.
  3. OAuth 클라이언트를 웹 애플리케이션으로 만들고, 실제 사용 주소(예: http://localhost:8000)를 승인된 JavaScript 원본에 추가합니다.
  4. 생성된 클라이언트 ID를 위에 붙여넣고 저장한 뒤 연결합니다.
중요: OAuth는 파일을 더블클릭한 file:// 주소에서 동작하지 않습니다. 간단한 로컬 웹 서버나 HTTPS 웹 호스팅에서 이 파일을 열어야 합니다. 클라이언트 보안 비밀은 이 파일에 넣지 마세요.

캘린더를 전체 공개한 경우 로그인 없이 표시할 수 있습니다.

  1. Google Cloud에서 Calendar API를 켜고 API 키를 생성합니다.
  2. Google 캘린더 설정에서 해당 캘린더를 공개합니다.
  3. 가능하면 API 키를 Calendar API 및 사용 도메인으로 제한합니다.

기본 캘린더는 계정 이메일과 같습니다. 별도 캘린더라면 Google 캘린더의 ‘캘린더 통합’에서 ID를 확인하세요.
